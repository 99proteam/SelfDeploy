Everything you need to ship

Git push to deploy

GitHub, GitLab, Gitea/Forgejo and Bitbucket webhooks, private repos, monorepos and preview deployments per pull request.

Any stack

Dockerfile, Docker Compose, any image, static sites and SPAs, or Node.js, Python, Go, PHP, Ruby, Rust, Java and .NET via Nixpacks.

Automatic SSL

Free Let's Encrypt certificates for every domain, issued and renewed automatically, with HTTP to HTTPS redirects.

Custom & wildcard domains

Several domains per app, a wildcard domain for new apps, and a free sslip.io URL that works before you touch DNS.

Zero downtime & rollback

New versions must pass a health check before traffic switches. Roll back to any earlier build in seconds.

Databases & backups

PostgreSQL, MySQL, MariaDB, MongoDB and Redis in one click, with scheduled backups to any S3-compatible storage.

Email server

SMTP, IMAP, DKIM, SPF, DMARC and spam filtering for your domains, with the exact DNS records shown for you.

One-click apps

WordPress, Ghost, n8n, Uptime Kuma, Gitea, Vaultwarden, Umami, Nextcloud, Grafana and more.

Light & simple

One Go binary with SQLite and an embedded dashboard, using about 20 MB of RAM. Manage remote servers over SSH.

Custom domains and HTTPS, built in

  1. Create an A record for app.example.com pointing to your server's IP.
  2. Add https://app.example.com to the app and redeploy.
  3. The certificate is issued within a minute and renews automatically. Ports 80 and 443 must be open.

For many apps, add a wildcard record *.apps.example.com once and every new app gets its own HTTPS subdomain.

FAQ

Is SelfDeploy free?

Yes. It is open source under the MIT license. You only pay for your own server.

How is it different from Heroku, Vercel or Netlify?

It runs on a server you control, so there are no per-app fees, usage limits or vendor lock-in, and your data stays with you.

What server do I need?

Any Ubuntu or Debian VPS with 1 GB of RAM (2 GB or more recommended). The installer sets up Docker for you.

How does SSL work?

SelfDeploy runs the Traefik proxy, which requests a free Let's Encrypt certificate for each domain over the HTTP-01 challenge and renews it before it expires.

Can I host email?

Yes, with the built-in mail server. Many cloud providers block outbound port 25 by default, so ask them to unblock it or relay through an SMTP provider.
